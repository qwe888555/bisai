## 1. CSV 数据模板

编码统一 utf-8（兼容 Excel BOM）。下列为**模板行**（仅示意格式，非正式数据），实际文件由负责人按模板列名产出后传给对应 `--*-csv` 参数。

### 1.1 区划（阶段 regions，唯一键 code）

```csv
code,name,level,parent_code,sort_order,is_active
<6位国标码>,<省/市/县名>,1,,0,1
<6位国标码>,<市州名>,2,<省级code>,0,1
<6位国标码>,<区县名>,3,<市州code>,0,1
```

校验规则（导入器强制）：level ∈ 1/2/3；省级不得有 parent_code；非省级必须有 parent_code 且父级先导入；按 level 升序自动排序。

字段规范（与冻结模型 [persons/models.py](../backend/apps/persons/models.py) 一致）：

| 列 | 必填 | 规范 | 对应模型列 |
|---|---|---|---|
| code | ✓ | 国标区划码，≤12 字符，全表唯一（重复行幂等跳过） | `Region.code` VARCHAR(12)，uk_region_code |
| name | ✓ | 区划名，≤50 字符 | `Region.name` VARCHAR(50) |
| level | ✓ | 1=省 / 2=市州 / 3=区县 | `Region.level` SmallInt（RegionLevel 枚举） |
| parent_code | level≥1 时必填 | 必须为已导入的上级 code；省级留空 | `Region.parent` 自引用 FK（PROTECT） |
| sort_order | 可空（默认 0） | 整数排序 | `Region.sort_order` |
| is_active | 可空（默认 1） | 1/0（是/true/y 亦接受） | `Region.is_active` |

数据来源：官方行政区划名录（待用户/组委会签发，**不得用网上抓取的第三方数据充当正式名录**）。

### 1.2 学校（阶段 schools，唯一键 (name,region)，code 可空唯一）

```csv
name,school_type,region_code,code,address,is_active
<校名>,PRIMARY,<区县code>,<学校标识码可空>,<地址可空>,1
```

校验规则：school_type ∈ PRIMARY/JUNIOR/SENIOR/NINE_YEAR/COMPLETE/MIDDLE_VOC（DDL 冻结编码）；region_code 必须已导入。

字段规范（与冻结模型一致）：

| 列 | 必填 | 规范 | 对应模型列 |
|---|---|---|---|
| name | ✓ | 校名，≤100 字符；唯一键半 (name,region) | `School.name` VARCHAR(100) |
| school_type | ✓ | 6 枚举之一（导入器硬校验，与 SCHOOL_TYPE_CODES 同源） | `School.school_type` VARCHAR(20) |
| region_code | ✓ | 必须已存在于 base_region（外键前置） | `School.region` FK |
| code | 可空 | 学校标识码 ≤20 字符，唯一；留空写 NULL（多 NULL 合法） | `School.code` VARCHAR(20) 可空唯一 |
| address | 可空 | 地址，写 NULL 兜底 | `School.address` |
| is_active | 可空（默认 1） | 1/0 | `School.is_active` |

数据来源：参赛学校名单 CSV（待用户/组委会签发；须含学校标识码与归属区县，**依赖区划先导入**）。

### 1.3 字典项（阶段 dict_items，唯一键 (type,value)）

```csv
type_code,value,label,sort_order,is_active,ext_json
school_type,PRIMARY,小学,10,1,
team_category,PRIMARY,小学组,10,1,
position,GK,守门员,10,1,
coach_category,HEAD,主教练,10,1,
```

**草案文件**：[docs/csv/dict_items_draft.csv](csv/dict_items_draft.csv)（2026-10-24 盘点产出，18 行：school_type 6 + team_category 2 + position 4 + coach_category 6；coach_level/guardian_relation 无数据源**不入草案**）。草案已通过真实库只读预览校验（新增=18 失败=0，未写入）；**草案 ≠ 正式数据**，各类型确认状态见 §1.5 矩阵，导入前须按 §6 审批清单逐项确认。

校验规则（导入器强制，2026-10-24 补齐 7 项全覆盖）：type_code 必须已存在于骨架（外键）；value/label 必填；value 匹配 `^[A-Za-z0-9][A-Za-z0-9_-]{0,49}$`（稳定编码，列宽 VARCHAR(50)）；同 type_code 下 label 重复 → 整体拦截（写库前零写入）；ext_json 合法 JSON 且存对象；(type,value) 重复幂等跳过；行级失败不阻断其余行。label 可改、value 稳定禁改。

字段规范（与冻结模型一致）：

| 列 | 必填 | 规范 | 对应模型列 |
|---|---|---|---|
| type_code | ✓ | 必须为 base_dict_type 已有 code（≤50 字符，蛇形规范） | `DictItem.type` FK→DictType |
| value | ✓ | 稳定编码：字母/数字开头，仅字母数字下划线连字符，≤50 | `DictItem.value` VARCHAR(50)，唯一键半 |
| label | ✓ | 展示名 ≤100；同 type 下不得重复（预检拦截） | `DictItem.label` VARCHAR(100) |
| sort_order | 可空（默认 0） | 整数 | `DictItem.sort_order` |
| is_active | 可空（默认 1） | 1/0 | `DictItem.is_active` |
| ext_json | 可空 | 合法 JSON 对象（存 JSONField，非字符串） | `DictItem.ext_json` |

| 9 | 执行后核验 | ✅ 已实现（须人工触发） | `--verify` 只读体检：ERROR/WARN/INFO 三级+`--strict`（WARN 亦失败）+退出码 0/1；**--execute 不会自动触发核验**，须按 §5 手工执行并留存输出 |

**已知缺口（本轮记录，不做实现——属后续迭代或待批准项）**：

1. 组织树/初始管理员两阶段不存在（§4.1/§4.2，决策 #5/#6/#7 待批）。
2. `--execute` 后无自动核验钩子（靠 §5 规程人工保证；如需自动化属代码变更，另行授权）。
3. material_types 的 `allowed_ext` 仅透传不校验取值内容（默认值兜底）；`max_size_mb` 非整数按行失败隔离。
4. schools 的 `code` 空串场景：导入器写 NULL 正确，但绕过 ORM 直改可能产生空串占唯一键——--verify 已有 WARN 防御（仅直改可达）。
5. 预览模式对 `dict_types` 之外阶段的"依赖前置不满足"（如学校 CSV 引用未导入区划）按行失败报告呈现，不前置整体拦截——单行失败隔离语义的一致延伸，非缺陷。

### 7.1 标准操作规程（导入前预览 → 执行 → 执行后核验）

每批数据（任一阶段）按以下顺序执行并留存输出，缺一不可：

```powershell
# ① 导入前预览（只读）：确认"新增"行数与签发数据源行数一致、失败=0
python manage.py init_base_data --phase <阶段名> --<阶段名>-csv 路径.csv

# ② 执行写入（须业务逐批授权，本轮及未授权批次禁止）
python manage.py init_base_data --phase <阶段名> --<阶段名>-csv 路径.csv --execute

# ③ 执行后核验（只读，必须留存输出作初始化验收记录）
python manage.py init_base_data --verify          # 退出码须为 0
python manage.py init_base_data --phase <阶段名> --<阶段名>-csv 路径.csv   # 幂等复跑：新增=0 跳过=N
```

判定标准：③ 的 verify 无 ERROR（WARN 逐条人工处置并记录）；幂等复跑新增=0；预览首屏"当前行数"=数据源行数合计。任一不满足即停下核查，不得重试覆盖。
