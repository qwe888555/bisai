## 4. 地址失效后如何获取最新地址

cpolar 重启（或电脑重启）后域名会变。本机取最新地址：

```powershell
# 隧道日志在部署副本目录
Get-Content D:\project_ldx\bisai_main_deploy\cpolar_restart.log | Select-String "Tunnel established"
```

取 `https://` 那行的域名即为最新公网地址。隧道转发目标固定为 `127.0.0.1:8000`。
