# 成员5 · 赛事门户接口文档

> 模块：apps/events | 路由前缀：/api/v1 | 共 62 个接口（53 个需登录 + 9 个公开）
> 基线：Django 5.2 + django-ninja 1.3 | 分支：ldx

---

## 通用约定

### 响应信封

所有接口统一返回：

```json
{ "code": "OK", "message": "成功", "data": {}, "requestId": "req_xxx" }
```

分页接口 data 为 { items: [], page, pageSize, total }。

### 认证

- 管理端接口：Authorization: Bearer <token>（JWT）
- 公开端接口（/public/*）：免登录

### 错误码

| HTTP | code | 含义 |
|---|---|---|
| 400 | INVALID_ARGUMENT | 参数校验失败 |
| 401 | UNAUTHORIZED | 未登录/token 失效 |
| 403 | FORBIDDEN | 角色/权限点不足 |
| 404 | NOT_FOUND | 资源不存在 |
| 409 | VERSION_CONFLICT / STATE_CONFLICT | 乐观锁版本冲突 / 状态不允许 |
| 422 | BUSINESS_VALIDATION_FAILED | 业务规则校验失败 |

### 角色

| 角色 | 权限 |
|---|---|
| ADMIN | 全部 |
| PROVINCE_REVIEWER | 赛事/组别/内容/赛果审核 |
| MATCH_RECORDER | 对阵/事件/直播/赛果录入 |
| 其他角色 | 报名可见接口 + 赛事详情只读 |

### 通用规则

- 写操作（POST/PUT/DELETE）需携带 version（乐观锁），冲突返回 409
- 比赛事件创建需请求头 Idempotency-Key（8–128 字符）
- 删除均为软删除

## 1. 赛事管理（6 个）

| # | 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|---|
| 1 | GET | /events | ADMIN, PROVINCE_REVIEWER | 分页查询赛事 |
| 2 | POST | /events | ADMIN, PROVINCE_REVIEWER | 创建赛事 |
| 3 | GET | /events/{eventId} | 全角色（只读） | 赛事详情 |
| 4 | PUT | /events/{eventId} | ADMIN, PROVINCE_REVIEWER | 修改赛事 |
| 5 | DELETE | /events/{eventId} | ADMIN, PROVINCE_REVIEWER | 删除赛事（需 version） |
| 6 | GET | /available-events | 全角色 | 报名可见赛事列表 |

查询参数（#1）：name, season, status, eventCategory（均可选）

请求体（#2 创建）：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| name | string | 是 | 赛事名称 1–200 |
| season | string | 是 | 赛季 1–30 |
| eventCategory | string | 否 | 赛事分类 |
| registrationOpensAt | datetime | 是 | 报名开始时间 |
| registrationClosesAt | datetime | 是 | 报名截止时间 |
| status | enum | 否 | DRAFT/REGISTRATION_OPEN/REGISTRATION_CLOSED/RUNNING/FINISHED，默认 DRAFT |
| description | string | 否 | 描述 ≤5000 |

响应字段（event_out）：id, name, season, eventCategory, registrationOpensAt, registrationClosesAt, status, currentPhase, phaseStartedAt, phaseEndsAt, progressPercent, description, version, createdAt, updatedAt

赛季进度（currentPhase / phaseStartedAt / phaseEndsAt / progressPercent，由赛事状态机派生，events 域不含初审/终审审核流程）：
- currentPhase：NOT_STARTED（DRAFT）/ REGISTRATION（报名阶段）/ COMPETITION（比赛阶段）/ FINISHED（已结束）
- phaseStartedAt / phaseEndsAt：报名阶段=报名窗口起止；比赛阶段=首场/末场 kickoff（无比赛场次时为空）；已结束=首场/末场或报名窗口兜底
- progressPercent：报名阶段=报名窗口已过时间占比（REGISTRATION_CLOSED 恒 100）；比赛阶段=已结束场次/总场次（无场次为 0）；已结束=100；DRAFT=0

## 10. 赛果管理（4 个）

| # | 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|---|
| 49 | GET | /matches/{matchId}/result | MATCH_RECORDER, ADMIN, PROVINCE_REVIEWER | 赛果信息 |
| 50 | PUT | /matches/{matchId}/result | 同上 | 保存/修改赛果 |
| 51 | POST | /matches/{matchId}/result/publish | 同上 | 发布赛果 |
| 52 | DELETE | /matches/{matchId}/result | 同上 | 撤下赛果（需 version） |

请求体（#50 保存）：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| version | int | 是 | 比赛版本 |
| resultType | enum | 是 | NORMAL/FORFEIT/ADMIN_CORRECTION |
| manualHomeScore | int | FORFEIT/ADMIN_CORRECTION 必填 | 人工主队比分 |
| manualAwayScore | int | 同上 | 人工客队比分 |
| reason | string | FORFEIT/ADMIN_CORRECTION 必填 | 原因 |

规则：
- NORMAL：比分由有效进球事件自动派生，忽略人工分
- FORFEIT/ADMIN_CORRECTION：仅 ADMIN/PROVINCE_REVIEWER 可用，录入员尝试返回 403
- 发布赛果仅允许比赛状态为 FINISHED，否则 409
- 撤下不删底层事件，回到 NORMAL 由事件重算

响应字段（match_result_out）：matchId, resultType, homeScore, awayScore, reason, published, sourceScoreRevision, version
