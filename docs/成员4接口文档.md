## 1. /base-data 基础数据路由契约（21 条）

模块：`backend/apps/persons/api.py`（router tags=["base-data"]，L46）、`persons/schemas.py`、`persons/services.py`。

### 1.1 总则

- 鉴权：JWTAuth；响应统一信封 `EnvelopeOut`（读=`ok`/分页，写返回对象，删=`action_result(true, id)`）。
- 权限：21 个权限点导入期 `register_operation`（api.py L50-73）。查询类 8 个 = ALL_ROLES（与 accounts dictionaryOptions 授权惯例一致，api.py L4-5）；写操作 13 个 = 仅 ADMIN。
- 审计：写操作统一 `audit_state()`（动作 `baseData.<域>.<操作>`，object_type/object_id/summary），由 AuditMiddleware 落 accounts_audit_log。
- 删除语义：Region / School / DictItem **只停用不删**（is_active=False）；DictType **无引用时物理删除、有引用 409**（api.py 模块注释 L8；services.py L322-328）。
- 分页：列表 `paginate(request, queryset, mapper=…)`；options 用 `paginate_list`（api.py L311）。

## 2. init_base_data 初始化命令契约

模块：`backend/apps/infra/management/commands/init_base_data.py`（幂等可重跑，默认只读预览）。

### 2.1 参数（8 个，L95-106）

| 参数 | 类型/默认 | 说明 |
|---|---|---|
| --phase | 默认 all；choices：all / dict_types / regions / schools / dict_items / material_types | 阶段选择 |
| --execute | store_true，缺省关闭 | 实际写入开关（缺省只预览） |
| --regions-csv | 路径 | 区划 CSV（列：code,name,level,parent_code,sort_order,is_active） |
| --schools-csv | 路径 | 学校 CSV（列：name,school_type,region_code,code,address,is_active） |
| --dict-items-csv | 路径 | 字典项 CSV（列：type_code,value,label,sort_order,is_active,ext_json） |
| --material-csv | 路径 | 材料类型 CSV（列：code,name,applies_to,is_required,need_audit,allow_multiple,allowed_ext,max_size_mb,sort_order,is_active,remark） |
| --verify | store_true | 只读验收；与 --execute 互斥，同给则 CommandError（L422-423） |
| --strict | store_true | 验收严格模式：存在 WARN 也返回非零退出码（L412-413） |

### 2.2 预检行为与执行边界

- **默认只读预览**：打印目标库与版本（MySQL 取 DATABASE()/VERSION()，SQLite 取 sqlite_version()，L110-121）、5 张表当前行数（base_region/base_school/base_dict_type/base_dict_item/material_type，L123-129）、各阶段就绪状态与缺失项；**不带 --execute 任何阶段（含提供了 CSV 时）都不写**（docstring 约定1；预览仅 exists 探测，L195-197/L224-226/L275-277/L308-310）。
- **幂等**：按业务唯一键 get_or_create，已存在一律跳过，不覆盖人工修改（docstring 约定2；L199/L228/L279/L312）。
- **不编造数据**：regions/schools/dict_items/material_types 缺 CSV 时明确跳过并记录（L166/L207/L236/L287）。
- **依赖顺序**：阶段固定 dict_types→regions→schools→dict_items→material_types（L435）；区划按 level 升序处理（父级先于子级，L170）；学校依赖已导入区划、字典项依赖字典类型。
- **事务边界**：--execute 时每阶段整体 `transaction.atomic()`（L438-442）；行级独立保存点，单行失败（含数据库级错误）只回滚该行并记入失败报告，不污染整批（L131-141、L198/L227/L278/L311）。
- **退出码**（--verify）：0=通过；存在 ERROR，或 --strict 时存在 WARN → sys.exit(1)（L412-413）。
- 本命令为数据级操作：不执行迁移、不修改冻结结构。

### 2.3 导入校验规则

- CSV 读取：utf-8-sig（兼容 Excel BOM）；多余列丢弃；缺失值按空串（L78-89）。
- 布尔解析：TRUE_SET = {1, true, yes, on, 是, y}，大小写不敏感（L69-75）。
- dict_types：仅 6 个骨架 code（team_category/position/coach_level/coach_category/guardian_relation/school_type，L54-61）；name 为建议值，可在执行前人工确认/修改。
- regions：code/name 必填；level ∈ {1,2,3}；省级（level=1）不得有 parent_code；非省级必须提供；parent_code 须已导入（L174-189）；唯一键 code。
- schools：name 必填；school_type ∈ SCHOOL_TYPE_CODES 6 值（PRIMARY/JUNIOR/SENIOR/NINE_YEAR/COMPLETE/MIDDLE_VOC，L64）；region_code 须已存在（L213-220）；唯一键 (name, region)，code 可空唯一。
- dict_items：type_code 须存在；value/label 必填；value 须匹配 `^[A-Za-z0-9][A-Za-z0-9_-]{0,49}$`（L46）；ext_json 须为合法 JSON 且存对象非字符串（L266-272）；**跨行同 (type_code, label) 重复 → CommandError 整批拦截**（L243-252）；唯一键 (type, value)。
- material_types：code/name 必填；applies_to ∈ {PERSON, TEAM, PERSON,TEAM（双归属）}；缺省 allowed_ext=jpg,jpeg,png,pdf、max_size_mb=10、need_audit=True（L293-307）；唯一键 code。

### 2.4 只读验收规则（--verify，L319-413）

分级口径：ERROR=违反冻结约束或已确认服务层规则；WARN=可疑但合法/依赖未确认清单；INFO=空表提示。

| 域 | 检查项与级别 | 依据 |
|---|---|---|
| dict_types | 空表 INFO；骨架 6 code 缺失 WARN（名称/清单未最终确认，不判硬错） | L327-333 |
| regions | level 非法 ERROR；父引用悬空 ERROR；省级有父 ERROR；非省级缺父 ERROR；父级 level≠level-1 ERROR；父级已停用 WARN；层级覆盖缺口（存在 level=3 缺 level=2 / 存在 level=2 缺 level=1）WARN | L336-363 |
| schools | school_type 非法 ERROR；空串 code 占唯一键 WARN；区划引用悬空 ERROR | L366-378 |
| dict_items | 字典类型引用悬空 ERROR；挂骨架外类型 WARN（正式清单未确认，人工确认级） | L381-392 |
| material_types | 空表 INFO；applies_to 非法 ERROR | L395-400 |

实现注记：验收用全表预加载构建 pk 映射而非 select_related——JOIN 会把悬空父级引用行从结果集丢弃导致防御检查失效（L338/L368/L383 注释）。
