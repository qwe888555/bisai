```python
# 1) 路由 + 权限 + 分页（一个列表接口的完整形状）
from ninja import Router
from apps.common.authentication import JWTAuth
from apps.common.pagination import paginate
from apps.common.permissions import ADMIN, register_operation, require
from apps.common.schemas import EnvelopeOut

router = Router(tags=["accounts"])
register_operation("accountList", (ADMIN,))     # 导入期登记，没有它会直接报错
_auth = JWTAuth()

@router.get("/accounts", auth=_auth, response=EnvelopeOut, summary="账号列表")
def list_accounts(request):
    actor = require("accountList")              # 校验登录 + 角色 + 权限点
    return paginate(request, services.list_accounts(actor), mapper=to_out)
```

```python
# 2) 请求模型：多传字段会被拒（400 INVALID_ARGUMENT）
from apps.common.schemas import StrictSchema

class AccountCreateIn(StrictSchema):
    username: str = Field(..., min_length=3, max_length=50)
    displayName: str = Field(..., min_length=1, max_length=50)
```

```python
# 3) 枚举、动作类返回、业务异常、审计
from apps.common.envelope import action_result, ok
from apps.common.errors import STATE_CONFLICT, ApiError
from apps.common.middleware import audit_state

if enrollment.status != "DRAFT":
    raise ApiError(STATE_CONFLICT, "仅草稿状态可提交")   # 409 契约信封
audit_state(request, "enrollment.submit", object_type="Enrollment", object_id=enrollment.pk)
return action_result(True, object_id=enrollment.pk, version=enrollment.version)
```

```python
check_version(enrollment, payload.version)
enrollment.status = "SUBMITTED"
bump(enrollment)
enrollment.save()
```

## 七、每日站会与验收标准

站会（15 分钟，每天固定时间）三句话：昨天完成什么、今天做什么、卡在哪、需要谁配合。成员2 负责记阻塞并在当天解决环境问题。

每个模块的验收标准（DoD），缺一条不算完成：
1. `python manage.py check` 无问题，`python manage.py runserver` 能启动，`/api/v1/docs` 能看到自己的接口；
2. 请求模型继承 `StrictSchema`，未知字段被拒（400 `INVALID_ARGUMENT`）；
3. 权限用 `register_operation` + `require` 实现，越权返回 403 契约信封（不是 500）；
4. 写操作带乐观锁 `version`，冲突返回 409；需幂等的操作带 `Idempotency-Key`；
5. 响应体是 `{code, message, data, requestId}`，分页 data 是 `{items, page, pageSize, total}`；
6. 敏感字段脱敏，日志里没有完整证件号/手机号；
7. 冒烟覆盖：正常路径、403 越权、409 冲突三种。
